# ShopEasy - Simple Shopping Website

A simple shopping website with multiple product categories, a contact form, and a hidden CTF challenge.

## Features

- Homepage with featured products
- Product categories (Electronics, Clothing)
- Contact form
- Hidden CTF challenge
- System logs

## Project Structure

```
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── products/
│   ├── electronics.html
│   └── clothing.html
├── contact.html
├── robots.txt
├── sitemap.xml
└── logs.txt
```

## Setup

1. Clone the repository:
```bash
git clone https://github.com/yourusername/shop-easy.git
```

2. Open `index.html` in your web browser to view the website.
